## Description

PharmAtlas is a private medication organization workspace for individuals and caregivers. Build reusable schedules and regimens, document administration history, track inventory, prepare medication packs, create labels, and review monitoring information in one place.

Flexible scheduling supports daily, weekly, every-other-day, interval, PRN, and user-specified routines. Individual doses can be retimed without changing the rest of an order, or future doses can be rescheduled together when the routine changes.

PharmAtlas also includes linked-order safeguards, prepack and return workflows, inventory alerts, printable reports, medication adherence summaries, caregiver notes, monitoring reminders, barcode recognition, and backup and restore.

Data is stored on the device. Information leaves the device only when the user deliberately exports, shares, emails, backs up, or stores files in a synchronized location.

PharmAtlas is intended for personal organization and caregiver documentation. It does not provide medical advice, prescribe treatment, replace a pharmacist or clinician, or provide emergency services. Always verify medication instructions and changes with a licensed healthcare professional.
